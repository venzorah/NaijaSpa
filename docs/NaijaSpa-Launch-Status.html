Founder briefing

Launch status

A plain view of what is already built in the NaijaSpa product, and what must still be connected before paying customers can book for real.

Date: 24 October 2026
Code: github.com/venzorah/NaijaSpa
Live target: naijaspa.com on Vercel · Postgres on a VPS

Product in code
Customer, vendor, and admin apps are built: search, booking flow, PWA, Paystack wiring, galleries, split login, Explore directory.
Not live for money yet
Real bookings need Vercel env connected to Postgres on the VPS, live Paystack keys, domain HTTPS, legal copy, and at least one real vendor. Until then it is a preview.

Dark Room / 18+ stays a homepage teaser only — it is not a product to launch.

  • Home hero with treatment slides and premium vendor ads
  • Find a therapist: treatment, state, city — Use my location opens Explore
  • Statewide coverage (Abuja / FCT as one area); GPS sorts, does not hide therapists
  • Explore directory with sidebar filters and provider cards
  • Provider / service pages with swipeable photo gallery
  • Stepped booking, Paystack checkout, account, bookings, favourites
  • Ask NaijaSpa AI (catalog search; LLM optional)

Vendor

  • Onboarding, services, Hotel / Home add-on prices
  • Therapist galleries (admin-capped images; video on paid plans)
  • Bookings, earnings, subscriptions

Admin

  • Vendor invite and commercial settings (commission, gallery limits, home rails, plan prices)
  • Finance of verified payments only
  • CMS placeholders for about, contact, privacy, terms

Recent product polish

  • Client and SPA Therapist signup on one themed split screen
  • Google / Gmail sign-in path
  • Explore restyled as a discover-providers directory
  • Homepage finder no longer jumps back to the hero after location
  • Where (spa / hotel / home) removed from the homepage search card

Engine

  • Next.js 15 on Vercel, Prisma 6, PostgreSQL on the VPS, amounts in kobo (NGN)
  • Bookings confirm only after Paystack verify or signed webhook
  • No card numbers stored

2. Must-do before a real launch

The app (pages and API) stays on Vercel. The database is PostgreSQL on a VPS — not Supabase. Set DATABASE_URL in Vercel to the VPS Postgres host.

Blocker What “done” looks like Status
VPS Postgres Install PostgreSQL 14+ on the Ubuntu VPS (not Supabase). Require SSL. Firewall: only Vercel (or a bastion) may reach port 5432. Set Vercel DATABASE_URL to postgresql://USER:PASS@VPS_IP:5432/naijaspa?sslmode=require. Run prisma migrate deploy against that URL. Demo catalog off. Blocked
Secrets & APP_URL Vercel project env: AUTH_SECRET, APP_URL=https://naijaspa.com, Paystack live keys, DATABASE_URL. Never commit secrets. Blocked
Paystack live Approved live account. Webhook https://naijaspa.com/api/payments/webhook for charge.success. One real paid booking confirms. Blocked
Domain & HTTPS Point naijaspa.com (and www) at the Vercel project. TLS is on Vercel. Old marketing page replaced. Blocked
Commercial prices Admin sets weekly / monthly / six-month vendor plan prices (seeded at ₦0). Admin
One real vendor Approved public spa with services, city/state, photos. Not demo Osun / Olive / Maitama Hands. Blocked

5. You may call it launched when

  • naijaspa.com serves this app from Vercel over HTTPS
  • Postgres on the VPS is live, Vercel can reach it, and the demo catalog is off
  • A new customer can register, search a state, book, pay Paystack, and see confirmed
  • The vendor sees the booking and a pending earning
  • Admin sees the payment as success
  • Privacy and terms are real documents
  • Backups exist and the Paystack webhook is green on a live charge.success

Until every box is true, NaijaSpa is a preview.

6. Launch-week order of work

  1. Provision the VPS with PostgreSQL only (SSL on, 5432 firewalled). Not Supabase.
  2. Set Vercel env: DATABASE_URL, AUTH_SECRET, Paystack keys, APP_URL=https://naijaspa.com.
  3. From a machine that can reach the VPS: prisma migrate deploy. Do not seed demo people.
  4. Staging: Paystack test charge against a preview deployment.
  5. Admin: plan prices, commission, gallery limits.
  6. Invite 1–3 real vendors; they add services and photos (durable object storage, not Vercel disk).
  7. You book and pay a real ₦ amount; confirm booking and earning.
  8. Point naijaspa.com at Vercel. Watch webhook 200s and Vercel logs for 24 hours. Take a pg_dump on the VPS.
